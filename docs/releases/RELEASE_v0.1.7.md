# 🌟 Antigravity Theme & Skin v0.1.7 发布说明

本版本为 **Windows 开机动画补丁持久化专项版**：修复了「重启电脑后皮肤/开机动效变回官方原样」的顽疾，并新增**开机自愈守护**，从此客户端自动更新覆盖 `app.asar` 后也能自动把开机动效补回来。

---

### 🐛 缺陷修复

#### 1. 彻底解决“重启后变回原样 / 开机动效消失” (BUG-020)
- **根因诊断**：
  其一，`scripts/install.mjs` 的部署白名单漏掉了 `loadingOverlay.js`（`install.ps1` / `install.sh` / `pack.mjs` 都有），导致插件目录缺文件 → 开机动效补丁注入直接失败；
  其二，Antigravity 客户端**每次自动更新都会整体替换 `resources/app.asar`**，注入其中的开机动效补丁必然被官方文件覆盖，且无任何自愈机制；
  其三，开发调试阶段通过 `hot-sync` 做的 CDP 热注入只存在于当前渲染进程，进程退出即失效，容易被误认为“已经装好了”。
- **修复方案**：
  - 补全安装白名单（`loadingOverlay.js`、`provisionSplash.js`、`self-heal.bat`）；
  - 安装全流程结束后自动**校验补丁标记**，未命中即报错提示，不再“静默成功”。

#### 2. Sidecar 内读取 `app.asar` 恒失败导致状态误报
- Electron 宿主会劫持 `fs`，对 `*.asar` 路径的 `readFileSync` 会被当作“读取 asar 内成员”而抛 `ENOENT`，使外观设置里的补丁健康状态恒显示「缺失」；
- 改用 `original-fs` 读取原始归档，状态探针现可 100% 准确判断补丁是否在位。

### ✨ 新增特性

#### 🛡️ 开机自愈守护（Windows）
- **零权限依赖**：注册到用户启动文件夹 `Startup\AntigravitySkinSelfHeal.vbs`，通过 `wscript` 隐藏启动，无需管理员权限、不会闪黑框，也不依赖容易被策略拒绝的计划任务（实测非管理员账户下 `schtasks` / `Register-ScheduledTask` 均返回 `0x80070005`，失败时自动降级为 `HKCU\...\Run`）。
- **快路径**：登录后延迟 10 秒自检，补丁完好时 ~50ms 直接退出，零开销。
- **绝不打断会话**：检测到客户端正在运行时**不杀进程**，只写入「待恢复」标记，顺延到下次登录自动补打。
- **全程留痕**：日志落在 `state/self-heal.log`（超 512KB 自动轮转），修复记录落在 `state/boot-patch.json` 供 UI 读取。
- **实测耗时**：补丁被覆盖后完整自愈（备份 → 解包 → 注入 → 重封 → 校验）约 **3.8 秒**。

#### 🔍 外观设置内可视化健康状态
- 「设置 - 外观 - 开机动效引擎修复」一行现在会实时显示：
  - `✅ 补丁已就绪 · 开机自愈守护已开启（客户端更新后下次登录自动恢复）`
  - `⚠️ 客户端更新已覆盖补丁，当前为官方原版开机动效，将在下次登录自动恢复；也可点击右侧立即修复`（按钮转为琥珀色高亮）
- 新增接口 `GET /api/boot-patch/status`，返回 `patched / pending / hasBackup / lastHealAt` 等字段。

#### 🩺 手动自检入口
- 新增 `self-heal.bat`：双击即立即自检并按需重打补丁，同时打印自愈守护的注册状态与最近一次自愈时间。

---

### 🍎 跨平台说明

- **🍎 macOS / Linux**：依旧保持 100% 零改包、非侵入式 CDP 守护架构，`self-heal` 与相关接口在这些平台自动跳过（`supported: false`），不会产生任何多余进程或自启动项。

### 🗑️ 卸载

- `uninstall.mjs` / `uninstall.ps1` / `uninstall.sh` 会自动注销自愈守护（启动项、隐藏启动器、历史计划任务）并还原官方 `app.asar`，不留残留。
