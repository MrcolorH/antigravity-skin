# 🌟 Antigravity Theme & Skin v0.2.9 发布说明

本版本为 **在线热更新后版本状态实时自动同步与闭环核验专项版**。彻底解决了此前客户端内执行热更新完成后，界面版本号不会立即刷新、必须用户手动再次点击「检查更新」才能确认已升级到最新版本的体验痛点。

---

### 🚀 核心改进与修复说明

#### 1. 热更新后状态立即刷新与陈旧缓存防倒退机制
- **根因诊断**：
  此前更新流程中，热重载完成注入后，`window.__AG_SKIN_VERSION__` 全局标记与组件闭包内缓存未能在第一事件轮次同步刷新为目标版本，且组件内的 `applyUpdateUI` 会读取未更新的缓存，导致界面重新渲染时一度把版本号回退显示为旧版本，更新按钮与提示也未完全重置。
- **治理与优化**：
  - 更新部署成功后，立即将 `window.__AG_SKIN_VERSION__` 全局变量和 UI 标签同步刷新为最新安装版本；
  - 在 `applyUpdateUI` 中建立**版本单调递增守护**：若远端版本不高于本地当前生效版本，强制校准 `hasUpdate = false`，彻底消除陈旧缓存导致旧版本号与更新按钮再度冒泡的可能；
  - Sidecar 热重载脚本在向主窗口注入新版 Bundle 时，提前注入已更新版本声明与干净的就绪状态，确保新旧生命周期无缝接力。

#### 2. 热更新后全自动触发后台复核检查更新
- 更新完成后无需用户任何手动干预，后台自动延迟触发一次深层版本复核检查；
- 自动对接本地 Sidecar / GitHub API 核验版本对齐情况，静默同步并确认「当前已是最新版本」，提供极致顺滑的零感知闭环体验。
