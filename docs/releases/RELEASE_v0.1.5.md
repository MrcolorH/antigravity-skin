# 🌟 Antigravity Theme & Skin v0.1.5 发布说明

本版本为 **macOS & Windows 跨平台冷启动防闪与开屏影院级平滑接力专项版**，彻底消除了 macOS 平台冷启动期间由官方原生遮罩自毁引发的“黑屏白屏跳变”断层，实现了全平台一致的开屏零白闪、零黑闪与秒级丝滑过渡。

---

### 🐛 缺陷修复与核心改进

#### 1. 彻底解决 macOS 启动时“闪黑屏白屏再进开屏动画”问题 (BUG-019)
- **根因诊断**：
  macOS 恪守苹果 Gatekeeper 签名安全，系统 `app.asar` 保持 100% 官方原版未改动。启动时官方原生 `loadingOverlay.js` 会先挂载；当主窗口刚完成基本文档加载时，官方主进程即刻调用 `removeChildView` 移除遮罩。此时前端皮肤与开屏动效尚未渲染就绪，主窗口原生空白/浅色底板瞬间裸露上屏整整 100~300ms，造成刺眼的白闪；随后开屏视频才弹出，形成“黑屏 ➔ 白屏 ➔ 开屏动画”的断层割裂。
- **修复方案**：
  - **CDP 硬件级视口底板锁定（T=0ms）**：在 Sidecar 建立主窗口 WebSocket 握手的第 0 毫秒，立即通过 Chromium CDP 原生协议指令 `Emulation.setDefaultBackgroundColorOverride` 强制锁定视口底板为纯黑 (`#000000`)；
  - **最前置 0ms 纯黑根节点防御样式**：在 Client Bundle 注入最头部挂载纯黑防护，确保无论网络解析快慢，主窗口在 DOM 开始绘制的瞬间即为纯黑，与官方黑色遮罩严丝合缝衔接，物理抹除白闪；
  - **开屏平滑退出与底色覆盖安全释放**：开机动画退出时，渲染端自动清理防闪样式并通过 `/api/boot-finished` 通知 Sidecar 释放底层覆盖，视口无缝交还给动态壁纸与毛玻璃工作区。

#### 2. 素材库大目录扫描超时与容灾提示优化
- 将素材库扫描（`/api/wallpaper-library/scan`）超时阈值提升至稳健的 45 秒，并增加网络抖动自动重试机制；
- 增加了精准的超时与本地引擎离线友好提示，杜绝用户在大型 Steam 创意工坊扫描时产生卡顿误解。
