# Antigravity Skin & Theme v0.2.16 发布说明

## 📌 版本信息
- **版本号**：`v0.2.16`
- **发布日期**：2026-11-23
- **核心重点**：新增 AI 对话展示样式双模态自由切换（「💬 气泡卡片」与「✨ 模拟原版」）、正文与表格直透壁纸、独立代码块轻量磨砂底衬与高对比度文字阴影守护。

---

## 🌟 背景与功能亮点

在启用动态壁纸与毛玻璃自定义主题后，用户在对话界面的视觉喜好呈现多元化需求：
1. **气泡卡片模式（Bubble Mode）**：
   采用经典圆角磨砂毛玻璃卡片包裹每条 AI 消息与工具链响应，层次结构清晰分明，适合追求立体感、聚焦感与内容块状分区的用户；
2. **模拟原版直透模式（Native Mode）**：
   还原 Antigravity 官方原版极简无外框排版，去除 AI 消息外层卡片边界与底色，使正文、列表、表格直接浮现并直透动态壁纸。同时为代码块保留轻量独立磨砂底衬与语法高亮，既保有壁纸的通透纯净，又兼顾长文阅读的舒适性与代码对比度。

---

## 🛠️ 改造与更新详情

### 1. 外观配置面板沉浸式交互集成（`client/modules/appearance-menu.js`）
- **分段选择器（Segmented Control）**：在外观配置菜单的自定义主题项中新增「AI 对话样式 (Chat Style)」设置行，提供「💬 气泡卡片」与「✨ 模拟原版」快速切换胶囊。
- **动态描述与状态联动**：切换时实时展示模式说明，配置实时保存并在下次加载时自动维持状态。
- **无缝即时生效**：无需刷新页面，点击即可热重载 root 节点样式类 `agy-chat-native`，所见即所得。

### 2. 模拟原版样式体系与视觉对比度守护（`client/styles/glass-theme.css`）
- **外框与底色剥离**：在 `agy-chat-native` 模式下，移除 AI 回复卡片的背景磨砂底色、外边框与阴影，重置内边距与圆角，呈现官方纯粹的流线型排版。
- **代码块独立磨砂底衬**：对 `pre` 代码容器保留独立轻量磨砂底衬（`backdrop-filter: blur(14px)`）与细边框，防止代码关键字与动态壁纸复杂图案混色，保证语法高亮清晰锐利。
- **表格与引用块原生化适配**：
  - 针对 Markdown 表格去除厚重毛玻璃底，改用透明轻量化网格并附带高对比度文字阴影（text-shadow），无论亮色还是暗色壁纸均清晰易读。
  - 针对 Markdown 引用块（blockquote）去除底色与边框，采用原生精致单侧竖线风格。
- **主题与壁纸深浅自适应**：全面适配暗色壁纸、亮色壁纸以及系统原生暗黑/明亮主题，自动调整文字颜色与边框对比度。

### 3. 配置规范与引擎底座对齐（`config.default.json`, `client/index.js`, `sidecars/skin-engine/main.mjs`）
- 在出厂默认配置、客户端初始化生命周期及后台皮肤引擎守护进程中对齐 `chatStyleMode` 字段（默认 `"bubble"`），确保各模块协同一致。
