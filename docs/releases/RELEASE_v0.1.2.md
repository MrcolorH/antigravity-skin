# 🌟 Antigravity Theme & Skin v0.1.2 发布说明

本版本主要聚焦于 **macOS 平台稳定性与视觉体验专项优化**，彻底解决场景壁纸冷启动死锁、界面布局错位及海报穿帮问题，实现 macOS 环境下的零改包、零黑屏与秒级丝滑启动。

---

### 🐛 缺陷修复与体验优化清单 (macOS 专项)

1. **修复冷启动 10 秒死锁假死（[BUG-017](./docs/bugs/BUG-017_scene_boot_style_missing_and_session_loader_overflow.md)）**
   - **问题说明**：场景壁纸模式冷启动时由于遗漏基础样式注入，导致宿主深度就绪检测无法闭环，强制进入 10 秒超时死锁等待后才放行。
   - **修复效果**：全形态壁纸在第 0 毫秒强制确保核心样式就绪，就绪检测秒级通过，开机流程丝滑无阻。

2. **消除错位 Loading 菊花与全局滚动条溢出（[BUG-017](./docs/bugs/BUG-017_scene_boot_style_missing_and_session_loader_overflow.md)）**
   - **问题说明**：冷启动与进入首页时，左下角出现未定位的半截旋转 Loading 图标，同时触发视口滚动条溢出、主工作区向上偏移 32px。
   - **修复效果**：为会话切换 Loading 层赋予绝对内联安全防护，彻底杜绝视口变形与多余滚动条，图标仅在切换会话时居中按需淡入。

3. **彻底切除场景壁纸静态海报穿帮（零海报架构 Zero-Poster）**
   - **问题说明**：多图层 2D/3D 场景素材提取单张海报容易出现主角缺失、零件碎图或因加载延迟导致的黑屏。
   - **修复效果**：全面剔除静态海报与 `<img>` 标签，直接以原生 WebGL2 Canvas 承载，杜绝一切开机贴图穿帮与闪烁。

4. **开屏动画升格为场景装配 Loading 舱（Boot as Loading Shield）**
   - **问题说明**：旧逻辑在时间到达后机械退出，导致动态着色器尚未编译完成就暴露出半成品或黑屏。
   - **修复效果**：开屏动画建立真就绪防护舱，坚决遮蔽后台 GPU 纹理与着色器装配过程，检测到首帧成型后 500ms 电影级平滑溶出。

5. **macOS 与 Windows 架构物理级解耦**
   - **问题说明**：两套平台的生命周期与系统权限存在差异，Windows 补丁锁逻辑易反向干扰 macOS。
   - **修复效果**：macOS 恪守 Apple 沙箱签名安全，采用纯非侵入 CDP 动态守护跑道，与 Windows ASAR 补丁架构彻底物理隔离。
