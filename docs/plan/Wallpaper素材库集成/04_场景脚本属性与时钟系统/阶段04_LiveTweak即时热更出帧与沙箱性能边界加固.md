# 阶段04：Live Tweak 即时热更出帧与沙箱性能边界加固

> **所属子模块**：子模块四：场景脚本属性与时钟系统  
> **状态**：`已完成 (Completed)` · **优先级**：P0  
> **核心目标**：打通控件调整与 WebWallGL 底层渲染管线之间的零延迟即时通信通道（Live Tweak），实现所见即所得的极速出帧；加固脚本沙箱边界并完成端到端全量真机验收。

---

## 1. 核心技术痛点与架构诉求

1. **拒绝暴力重载（Zero Reload）**：  
   用户在调节时钟颜色、滑块数值或切换 24 小时制时，**绝对不能重新加载整个场景壁纸（不能重新解包 `scene.pkg` 或重编着色器）**。必须在当前运行中的 WebGL2 上下文与 SceneScript 运行时中实时打补丁；
2. **防抖与性能节流（Debounce & Throttling）**：  
   用户高频拖动 Slider 滑条时，若每毫秒都触发一次完整持久化或 GPU 重算，极易引起渲染帧率骤降。必须在 UI 响应与存储之间构筑 16ms rAF 节流防线与 300ms 存盘防抖；
3. **沙箱逃逸防御**：  
   确保任意恶意的或编写不规范的工坊脚本代码，无法通过原型链污染或执行越界破坏客户端。

---

## 2. 具体实施方案

### 2.1 WebWallGL `setProperties` 实时注入通道
1. 前端通过统一实例方法直接下发差异更新：
   ```javascript
   window.__agyWallpaperInstance.setProperties({
     [propertyKey]: propertyValue
   });
   ```
2. WebWallGL 接收到新属性后：
   - 立即同步到 `SceneScript` 的 `userProperties` 字典中；
   - 触发场景脚本的 `applyUserProperties(properties)` 钩子回调；
   - 着色器 Uniform 常量（如颜色、透明度）直接热写入 GPU 缓冲。

### 2.2 双层性能防护机制
```
[用户连续拖动 Slider]
        ↓
  16ms rAF 节流 ➔ 立即调用 setProperties() (画面 60fps 实时丝滑变幻)
        ↓
  300ms 延时防抖 ➔ 批量合并写入 config.json (零频繁磁盘 I/O 阻塞)
```

### 2.3 异常熔断与容灾
1. 对 SceneScript 的每帧 `update()` 计算与属性热更回调增加 `try...catch` 异常包装；
2. 一旦某张壁纸的第三方脚本发生语法或运算死循环，自动触发局部熔断，回落安全渲染模式，防止整个主窗口假死。
