# 阶段03：场景属性检查器面板（Inspector）与弹簧物理加载动效

> **所属子模块**：子模块四：场景脚本属性与时钟系统  
> **状态**：`待开发 (Pending)` · **优先级**：P1  
> **核心目标**：在外观设置面板构建如同 Wallpaper Engine / WallpaperMachine 的原生级属性检查器（Property Inspector），实现齿轮按钮挂载、弹簧阻尼抽屉动效与多态控件工厂。

---

## 1. 界面与交互定位（UI/UX）

### 1.1 ⚙️ 齿轮按钮定位与条件激活
1. **挂载位置**：  
   在「当前动态壁纸」信息行内，位于壁纸名称左侧或标题右侧；
2. **条件显隐**：  
   - 当当前激活的壁纸为 **Scene（场景）壁纸** 且检测到存在有效 `properties` 属性时，该齿轮高亮显示；
   - 当为静态视频（Video）或无属性壁纸时，齿轮按钮平滑淡出隐藏。

### 1.2 弹簧阻尼物理展开（Spring Physics）
点击齿轮按钮时：
1. **齿轮自旋反馈**：齿轮图标触发顺滑 90° 自旋过渡（`transform: rotate(90deg)`，耗时 280ms）；
2. **抽屉弹簧展开**：
   在信息行下方，采用弹簧阻尼曲线（`cubic-bezier(0.175, 0.885, 0.32, 1.275)`）向下弹性滑出独立的「场景属性配置抽屉」；
3. **关闭联动**：再次点击齿轮或点击抽屉内部收起按钮，抽屉平滑回弹收折。

## 2. 多态控件映射工厂（Control Factory）

抽屉内部依据属性元数据的 `type` 动态生成对应的原生级 UI 控件：

| 属性类型 (`type`) | 渲染控件形态 | 交互与即时响应逻辑 |
|:---|:---|:---|
| **`bool`** | iOS 风格平滑切换 Switch | 点击即时翻转布尔值，用于：时钟显隐、24小时制、显示秒钟、天气雨雪开关等。 |
| **`slider`** | 渐变滑条 + 实时数值气泡 | 拖动实时联动（加 16ms rAF 节流），用于：字体大小、动画速度、粒子密度、时钟透明度。 |
| **`color`** | 取色块 + 原生 HTML5 Color Picker | 点击弹出调色器，RGB 归一化向量（`"1.0 1.0 1.0"` $\leftrightarrow$ `#FFFFFF`）自动转换，用于：时钟文字颜色、发光特效等。 |
| **`combo`** | 毛玻璃圆角下拉选择框 Select | 选项即时切换，用于：时钟样式选择、语言切换、预设主题风格等。 |
| **`text`** | 紧凑文本输入框 Input | 输入即时生效（防抖 200ms），用于：自定义时钟问候语、用户名字等。 |

## 3. 视觉与布局规范
1. **毛玻璃暗色容器**：面板继承插件整体的毛玻璃视觉语言，内衬深色半透明背景（`rgba(15, 23, 42, 0.75)`）与微边框；
2. **紧凑排列**：控件采用两列或紧凑响应式流式布局，带有清晰的属性描述与当前取值标签；
3. **底部操作栏**：抽屉底部常驻「↺ 恢复作者默认」按钮与收起指示。
