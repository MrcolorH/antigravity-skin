# 子模块四：场景脚本属性与时钟系统 (SceneScript & Properties Inspector)

> **模块状态**：`当前正在进行 / 待启动 (In Progress / Next)`  
> **核心定位**：解决 Wallpaper 场景壁纸（Scene 类型）的 SceneScript 脚本引擎激活、系统时钟/日期流注入，以及可视化属性检查器（Property Inspector）与即时热更交互。

---

## 一、 需求痛点与对标设计

1. **时钟日期“完全读不了”**：  
   当前渲染引擎将脚本全局硬编码关闭（`scripts: false`），导致大量高热度创意工坊壁纸上的**数字时钟、日期日历、昼夜循环**停留为空白或 `<Clock>` 占位字符；
2. **场景脚本参数无法自定义**：  
   Wallpaper Engine 创作者在素材中提供了极其丰富的可调参数（12/24小时制切换、显隐秒针、粒子密度、时钟字体颜色、自定义文字等），目前客户端完全缺乏调节入口；
3. **交互对标 WallpaperMachine**：  
   深度对标 macOS 知名开源客户端 **WallpaperMachine** 的 Property Inspector 设计，在外观面板提供带有弹簧阻尼物理动效的属性抽屉。

## 三、 模块交付产出物清单
1. **SceneScript 运行时时钟支持**：自然读取现实时间，秒级走动；
2. **⚙️ 场景属性检查器抽屉**：丝滑弹簧展开与自旋微交互；
3. **多态属性映射表**：涵盖开关、滑条、取色器、下拉框、文本输入框；
4. **即时热调（Live Tweak）**：无需重载壁纸，改动即刻出帧；
5. **Per-Wallpaper 个性化存盘**：切换壁纸不丢配置，支持一键复原预设。
