# 阶段四计划：双开关交互重构与年龄分级筛选

> ✅ **已实施（0.2.0 引入，随 v0.3.0 一并发布）**：双开关、原生载入区隐藏、双色选中态、G/PG-13/R-18 分级筛选均已落地并通过无头浏览器 + 真实库验证，实测数据见《实现记录》§2.0 / §2.05 / §6。

> 本阶段**推翻并取代** [实现记录 §2.0](./实现记录.md) 中的「素材库单一总开关」模型。
> 冲突裁决：以本文件第 2 条（动态壁纸 / 开屏动画各自独立开关）为准；第 1 条（隐藏原生载入区、选中态外框）与第 3 条（年龄分级筛选）在其之上叠加。
> 落地完成后须回写《实现记录》，删除 §2.0 的单开关描述并追加阶段四章节。

## 1. 本阶段要解决的三件事

| # | 需求 | 现状问题 | 目标 |
| :--- | :--- | :--- | :--- |
| 1 | 开启素材库后不展示原生「选择动态壁纸 / 选择已载入的壁纸或导入新素材」及路径 | 现在原生下拉框与上传行仍在，只是候选被换成素材库条目，信息重复且有两条选择路径 | 原生选择区整体隐藏（含下拉框、删除按钮、上传行），代之以一行「当前：xxx ｜ 使用中」；素材库卡片用**对应动作颜色**的选中外框标识 |
| 2 | 动态壁纸与开屏动画**各自独立**的素材库开关 | 现在是单一开关，一开全开 | `wallpaperEnabled` / `bootEnabled` 双开关；任意组合合法；任一开启即把素材库区块移动到「插件版本与在线热更新」下方；卡片只展示对应的应用按钮 |
| 3 | 素材库增加年龄分级筛选 | 当前只有类型筛选 + 搜索 | 对齐 WallpaperMachine：`Everyone (G)` / `Questionable (PG-13)` / `Mature (R-18)`，默认全选=不筛选，取消勾选=排除 |

## 3. 详细设计

### 3.1 配置模型（双开关 + 迁移）

```json
"externalWallpaperLibrary": {
  "wallpaperEnabled": false,   // 动态壁纸使用素材库
  "bootEnabled": false,        // 开屏动画使用素材库
  "libraryPath": "",
  "autoScan": true,
  "mountedFolders": []
}
```

- **迁移规则**（Sidecar `normalizeConfig()`）：
  1. 若 `wallpaperEnabled` 与 `bootEnabled` 均未定义，而旧字段 `enabled === true`，则两者都置 `true`（保持用户此前的预期）；
  2. 其余情况缺失字段一律补 `false`；
  3. 旧字段 `enabled` 落地后不再写入，读取时忽略。
- 客户端 `wallpaper-library-ui.js` 通过 `isWallpaperEnabled()` / `isBootEnabled()` 读取，避免各处散落 `?.enabled`。
- 兼容性：旧版本若读回新配置，只认识 `enabled`，会当作关闭 —— 可接受（版本回退非目标）。

### 3.2 原生载入区隐藏与「使用中」替代行

**动态壁纸区**（`appearance-menu.js` 模板）：

| 元素 | 行为 |
| :--- | :--- |
| `#agy-wrap-video-path`（含「选择动态壁纸」标签 + `#agy-select-builtin-wallpaper` + 删除按钮） | `wallpaperEnabled` 时整体 `display:none` |
| `#agy-wallpaper-upload-row`（📂 载入新视频壁纸） | 同上隐藏（连同 accept 文件输入一起隐藏，不再暴露路径） |
| `#agy-wallpaper-active`（新增） | 库模式专用行：`当前动态壁纸：<标题>` + 【使用中】胶囊；无外部选择时显示「尚未从素材库选择」+ 引导文案 |
| 亮度 / 对比度滑块（`#agy-wrap-sliders`） | **保留**，与素材来源无关 |

**开屏区**：

| 元素 | 行为 |
| :--- | :--- |
| 素材形式分段控件 | 保留（代码动效模式下不显示库开关） |
| `#agy-wrap-boot-video-path` 内的选择行 + `#agy-boot-upload-row` | `bootEnabled` 时隐藏 |
| `#agy-boot-active`（新增） | 库模式专用行：`当前开屏素材：<标题>` + 【使用中】；开屏关闭（总开关）时不显示 |

「使用中」判定：壁纸取 `dynamicWallpaper.wallpaperDir`（非空即命中）；开屏取 `bootAnimationConfig.wallpaperDir`（`type === 'scene'` 或库模式视频）。UI 在 `applyLibraryModeUI()` 中统一重算。

### 3.3 素材库区块下移

- `#agy-wallpaper-library` 节点从「壁纸选择区下方」移动到 `#agy-wrap-plugin-update` **之后**（`insertAdjacentElement('afterend')`）。
- 显示条件：`wallpaperEnabled || bootEnabled`；两者皆关时整块 `display:none`（连标题行也不占位）。
- 幂等：每次 `integrateNativeMenu()` 执行时重新确认位置（若宿主重排 DOM 则自动纠正），避免重复插入。
- 语言切换 `rerender()` 仅重建区块内部，不改变其在面板中的位置。

### 3.4 卡片按钮按开关显隐

- `wallpaperEnabled` → 渲染「设为动态壁纸」按钮；否则不渲染。
- `bootEnabled` → 渲染「设为开屏动画」按钮；否则不渲染。
- 两者皆关 → 素材库区块本就不显示，无需处理空状态。
- 单按钮时按钮占满整行（`flex:1`），不做占位空洞。
- 卡片数据模型不变，仅渲染层按开关裁剪。

### 3.5 年龄分级筛选（对齐 WallpaperMachine）

**语义**（照搬 WallpaperMachine `LibraryFilterCatalog` 的 rating 组）：

| 标签（不翻译） | 界面文案 | 默认 | 交互 |
| :--- | :--- | :---: | :--- |
| `Everyone` | 所有人 (G) | ✅ 勾选 | 取消勾选 = 排除该分级 |
| `Questionable` | 辅导级 (PG-13) | ✅ 勾选 | 同上 |
| `Mature` | 限制级 (R-18) | ✅ 勾选 | 同上 |

- **排除模型**：三项默认全选 → 不筛选；取消勾选即隐藏该分级。与 WallpaperMachine「every box starts ticked, unticking excludes the tag」完全一致。
- **默认值依据**：WM 的 Installed 视图源码注释明确 *"The library is the user's own, so nothing is excluded by default."*，其 `isOffByDefault`（PG-13 / R-18 默认不勾）只作用于 **Discover（线上工坊浏览）**。本功能对齐的是本地库视图，故不做「默认隐藏成人内容」，避免与用户的库预期冲突；需要安全浏览时手动取消 R-18 即可（并记忆该偏好）。
- **标签不参与本地化**：匹配始终用 `Everyone/Questionable/Mature` 原值，界面文案单独映射（中文 `所有人 (G)`，英文 `Everyone (G)`）。
- **数据来源**：`project.json` 的 `contentrating`。缺失（本机实测 25 项）时按 Wallpaper Engine 默认视作 `Everyone`，并标记 `ratingInferred: true`（不展示给用户，便于排错）。
- **未知值**（未来新增分级的非空字符串）：归入 `unknown` 桶，默认**始终可见**且不提供排除项，仅在 `byRating.unknown` 计数中体现。本机实测为 0。
- **计数**：每个分级 chip 显示当前素材库内的数量（如 `G 200`），基于全量列表计算，不随其他筛选变化（与 WM 侧边栏计数一致）。
- **状态持久化**：存入 `localStorage['agy.lib.ratingFilter'] = { excluded: ['mature'] }`。原因：设置菜单会被 `MutationObserver` 反复重建 / 语言切换 `rerender()`，放内存会丢；放 config.json 又属于视图偏好而非插件配置。清空浏览器存储即回默认。
- **组合顺序**：类型筛选 → 分级筛选 → 关键词搜索 → 分页。状态行展示 `已索引 362 款 · 视频 167 / 场景 176 / 网页 19 · 已隐藏 145 款（分级）`。
- 与「素材库为空」提示的优先级：先判断库是否为空，再判断筛选结果为空；筛选结果为空时展示「当前筛选无匹配，试试放宽分级或类型」。

### 3.6 后端字段

`wallpaper-library.mjs` 的 `parseWallpaperFolder()` 返回值新增：

```json
{
  "rating": "everyone",          // everyone | questionable | mature | unknown
  "ratingRaw": "Everyone",       // 原始 contentrating
  "ratingInferred": false,       // contentrating 缺失、按 Everyone 兜底时为 true
  "ratingSex": "none",           // 原样透传，暂不参与筛选
  "ratingViolence": "none"
}
```

`scanLibrary()` 的 `stats` 增加 `byRating: { everyone: 200, questionable: 17, mature: 145, unknown: 0 }`（200 = 175 显式 Everyone + 25 缺失兜底），供前端 chip 计数（也允许前端自行统计，二选一；实现取后端返回，减少一次遍历）。

## 5. 兼容与迁移

1. **旧配置**：`enabled: true` → 双开关同开（一次性迁移，写入新字段）。
2. **旧壁纸状态**：`wallpaperDir` 已存在但新开关为关 —— 不强制切换，原生选择区显示「📁 当前外部素材：xxx」占位，行为与当前一致。
3. **旧前端缓存**：`localStorage` 无 `agy.lib.ratingFilter` 时按默认全选处理，不报错。
4. **热更新**：`sync-all.mjs` 已覆盖两个前端模块与 sidecar，无需改动；改完执行一次即可生效。

## 6. 关于旧 `enabled` 字段的处置

- 读取期兼容（见 §3.1），写入期只写新字段。
- `config.default.json` 保留 `enabled: false` 会让新老字段并存造成语义歧义，因此**从默认配置中移除** `enabled`，仅由 `normalizeConfig` 在读取旧文件时识别。
- `pack.mjs` 以 `config.default.json` 为出厂配置，故新装用户不会看到 `enabled`。

## 8. 风险与取舍

| 风险 | 说明 | 处置 |
| :--- | :--- | :--- |
| 双开关组合导致的空选择 | 例：壁纸库开但从未选过外部壁纸 | 「当前动态壁纸」行显示引导文案，不静默失败；已应用的素材继续播放 |
| 卡片按钮单边时布局塌陷 | 只渲染一个按钮 | 按钮 `flex:1` 撑满；卡片高度用 `min-height` 对齐 |
| 分级字段缺失 | 本机 25 项无 `contentrating` | 按 Everyone 兜底（`ratingInferred: true`），计入 everyone 桶，行为与官方默认一致 |
| 区块位置被宿主 DOM 重排 | 设置面板可能重建 | 每次 `integrateNativeMenu()` 校验并纠正位置（幂等 `insertAdjacentElement`） |
| 旧配置误迁移 | 用户曾开单开关，升级后双开 | 属预期（保持原有效果）；若只想其一生效，用户手动关另一个 |
