# 阶段 03：参数弹窗自定义配置与状态反馈 HUD

> 状态：**设计就绪（待实施）**　|　版本：v0.2.0　|　前置依赖：[阶段 02：WebWallGL 点击响应与双轨事件网桥](./阶段02_WebWallGL点击响应与双轨事件网桥.md)
>
> 📌 **核心目标**：提供完整的用户自定义交互控制体系。在既有的「壁纸显示与渲染设置」弹窗中无缝集成按键交互配置区（包含功能开关、触发修饰键下拉自定义、状态提示开关）；设计极轻量、自适应暗色风格的毛玻璃微态 HUD 药丸反馈。

---

## 1. 用户界面设计

### 1.1 弹窗配置区原型（`media-display-modal.js`）

在壁纸参数设置弹窗（Display Modal）底部，新增独立的 **「指针与点击交互 (Wallpaper Interaction)」** 配置分组：

```
┌────────────────────────────────────────────────────────┐
│ ⚙ 壁纸显示与渲染设置                                  ✕ │
├────────────────────────────────────────────────────────┤
│ 铺满方式        [ 智能自适应 (Auto) ▾ ]                 │
│ 渲染帧率        [ 60 FPS           ▾ ]                 │
│ 渲染精度        [ 1.0x (原生高清)   ▾ ]                 │
├────────────────────────────────────────────────────────┤
│ 指针与点击交互 (按键穿透)                              │
│ ├─ 启用按键交互穿透   [ ● 开启 / 关闭 ]                 │
│ │   └─ 按住指定键临时让鼠标事件直达壁纸，点击解压与互动  │
│ ├─ 激活修饰按键       [ Alt / Option (默认) ▾ ]         │
│ │   ├─ Alt / Option (推荐，不冲突打字)                 │
│ │   ├─ Shift                                           │
│ │   ├─ Control                                         │
│ │   └─ Command / Meta                                  │
│ ├─ 显示交互状态 HUD   [ ● 开启 / 关闭 ]                 │
│ │   └─ 按住激活时在屏幕右上角提示微型药丸                │
│ └─ 滚轮缩放与切页     [ ● 开启 / 关闭 ]                 │
└────────────────────────────────────────────────────────┘
```

### 1.2 极轻量微态 HUD 药丸设计
当用户按住触发键激活穿透时，屏幕右上角平滑淡入一个非打扰、半透明液态毛玻璃状态药丸：

```
┌──────────────────────────────────────┐
│  ⚡ 壁纸互动中 (松开恢复日常编写)    │
└──────────────────────────────────────┘
```

- **视觉规范**：
  - `position: fixed; top: 18px; right: 24px; z-index: 999999;`
  - 背景：`rgba(15, 23, 42, 0.75)`，带 `backdrop-filter: blur(12px)`；
  - 边框：`1px solid rgba(255, 255, 255, 0.12)`；
  - 字体：`12px`, 柔和亮灰文本，黄色/荧光绿微型能量指示灯 `⚡`；
  - 动画：淡入 150ms，淡出 120ms，松手即刻无痕移除；
  - `pointer-events: none`，绝不干扰任何鼠标点击。

## 2. 数据契约与持久化配置（`config.json`）

在客户端根配置或 `config.json` 中统一持久化：

```json
{
  "wallpaperInteraction": {
    "enabled": true,
    "modifierKey": "alt",
    "showHud": true,
    "enableWheel": true
  }
}
```

- **字段说明**：
  - `enabled` (boolean)：交互穿透总开关，默认 `true`；
  - `modifierKey` (string)：触发键，可选值 `"alt"`、`"shift"`、`"ctrl"`、`"meta"`，默认 `"alt"`；
  - `showHud` (boolean)：是否在按住时显示右上角 HUD 药丸，默认 `true`；
  - `enableWheel` (boolean)：按住时是否同步穿透鼠标滚轮事件，默认 `true`。
