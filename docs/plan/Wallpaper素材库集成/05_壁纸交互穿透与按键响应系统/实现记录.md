## 一、需求背景与业务价值

在原有的 Antigravity 皮肤系统中，动态壁纸作为视口底层的毛玻璃背景，其上层覆盖了 Monaco 编辑器、工作区 DOM 与 UI 交互层。所有鼠标点击事件均被宿主主窗口消费，壁纸处于纯被动展示状态。
而大量高质量的 Wallpaper Engine 壁纸（如包含多立绘人物切换、机关点击触发、Live2D/3D 木偶交互、可交互视差等）无法响应用户的点击操作。

为此，**子模块五**构建了一套「按键激活型鼠标事件穿透系统 (Hold-to-Interact & Dual-Track Event Bridge)」：
- **按住修饰键穿透（默认 `Alt` 键）**：按住设定按键时，鼠标事件穿透宿主工作区直达底层壁纸，光标呈现十字线交互态，屏幕右上角弹出 Liquid Glass 毛玻璃药丸 HUD 状态提示。
- **松键无感恢复日常**：松开按键后，瞬间解除穿透并恢复日常编码焦点，彻底杜绝误触或影响正常打字写代码。
- **双轨渲染引擎事件网桥**：无论是 WebGL2 场景壁纸（Scene 壁纸）还是 Web 网页壁纸（Iframe 壁纸），均无缝支持点击、拖拽、滚轮切页缩放与光标离开机制。
- **参数面板与实时热更新**：在外观设置主面板及独立参数弹窗中均提供可视化配置（开关、修饰键自定义、HUD 开关、滚轮开关），无需刷新即刻热生效。

## 三、各阶段落地细节

### 阶段 01：修饰键监听状态机与层级穿透引擎
- **配置规范预置**：在 [`config.default.json`](../../../config.default.json) 中新增 `wallpaperInteraction` 出厂配置。
- **状态机与按键监听**：在 [`client/modules/wallpaper.js`](../../../client/modules/wallpaper.js) 中构建 `isPierceActive` 状态机，捕获阶段监听 `keydown` / `keyup`。
- **系统菜单防劫持**：Windows 下按下 `Alt` 键调用 `e.preventDefault()`，防止触发原生窗口顶部菜单栏焦点抢占。
- **CSS 动态穿透注入**：注入 `#agy-wallpaper-pierce-style`，穿透激活时为 `html` 增加 `.agy-wallpaper-pierce-active`，将主工作区设为 `pointer-events: none !important; user-select: none !important;`，壁纸容器提升为 `pointer-events: auto !important; z-index: 99998 !important;`。
- **失焦恢复与安全避让**：监听 `window.blur` 与 `document.visibilitychange`，且穿透期间按下其他打字键时立即强制退出穿透态。

### 阶段 02：WebWallGL 点击响应与双轨事件网桥
- **TDZ 安全作用域声明**：在 `initWallpaper` 作用域顶部预声明 `let sceneRendererInstance = null;`，防止事件网桥闭包引用出现 TDZ 异常。
- **Scene 轨分发**：计算归一化坐标 `(u, v)`，分发 `pushPointer(u, v, buttons, mods)`，并完美兼容未激活态下的节流被动视角微随动。退出时派发 `pointerLeave()`。
- **Web 轨分发**：向壁纸 iframe 发送标准 Wallpaper Engine 协议格式：`postMessage({ __we: 1, op: 'pointer', x, y, b, m }, '*')`。
- **滚轮拦截与分发**：穿透态下对 `wheel` 事件调用 `preventDefault` 阻断宿主自身滚动条滚动，并转发 `pushWheel`。

### 阶段 03：参数配置与 Liquid Glass 状态反馈 HUD
- **状态反馈 HUD**：在屏幕右上角构建毛玻璃药丸 HUD，包含呼吸闪烁灯、`ALT` 键位徽章与操作提示，平滑淡入淡出。
- **参数设置面板双入口**：
  1. **外观主卡片快捷行**：在 `client/modules/appearance-menu.js` 的动态壁纸展开区域直接提供「壁纸按键穿透与交互 (Hold-to-Interact)」开关与修饰键下拉菜单。
  2. **独立参数弹窗**：在 `client/modules/media-display-modal.js` 中增加「🖱️ 指针与按键交互」控制项（包含总开关、修饰键、HUD 开关、滚轮开关）。
- **即时热更新通道**：用户在界面中拨动开关或切换按键时，调用 `wallpaperHandle.updateInteraction(...)` 实时热应用并落盘保存。
