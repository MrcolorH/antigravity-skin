# 阶段 01：修饰键监听状态机与层级穿透引擎

> 状态：**设计就绪（待实施）**　|　版本：v0.2.0　|　前置依赖：[02_多形态渲染与交互引擎](../02_多形态渲染与交互引擎/README.md)
>
> 📌 **核心目标**：构建生产力安全的「按住瞬时穿透（Hold-to-Interact）」状态机。通过全局修饰键（默认 `Alt`，支持自定义）监听，动态翻转宿主与壁纸容器的层叠上下文（Stacking Context）与 `pointer-events`，并提供 Windows 系统菜单防截获、输入法避让、失焦强制释放与宿主焦点抢救四重安全屏障。

---

## 1. 核心交互机制与状态机

### 1.1 状态机模型

```mermaid
stateDiagram-v2
    [*] --> Normal: 初始化完成
    Normal --> Piercing: 用户按下修饰键 (如 Alt)\n[条件: 未聚焦在文本输入/未失焦]
    Piercing --> Normal: 用户释放修饰键 (KeyUp)
    Piercing --> Normal: 窗口失焦 (Blur / Tab 切走)
    Piercing --> Normal: 切换壁纸或插件重置
    
    state Normal {
        [*] --> Idle
        note right of Idle: 宿主 pointer-events: auto\n壁纸 pointer-events: none\n日常代码编写 100% 正常
    }
    
    state Piercing {
        [*] --> PierceActive
        note right of PierceActive: 宿主 pointer-events: none\n壁纸 pointer-events: auto\n壁纸 z-index 临时提升\n光标直达底层壁纸
    }
```

### 1.2 生命周期细节

1. **按下修饰键（`KeyDown`）**：
   - 检查事件修饰符（如 `e.key === 'Alt'` 或 `e.altKey`）；
   - 若用户正在文本输入框（`INPUT`、`TEXTAREA`、Monaco 编辑器活动输入区）输入时，若仅按住单独修饰键，依然激活穿透；但若伴随其他字符键按下则立即退出穿透，避免干扰快捷键；
   - 拦截系统默认行为：在 Windows 系统中，按下 `Alt` 键默认会聚焦窗口顶部的系统菜单栏。必须在判定为独立修饰键时调用 `e.preventDefault()` 阻止菜单栏劫持；
   - 注入穿透标记：向 `document.documentElement` 添加类名 `agy-wallpaper-pierce-active`；
   - 记录当前处于焦点的宿主元素 `lastFocusedElement = document.activeElement`。

2. **释放修饰键（`KeyUp`）**：
   - 移除类名 `agy-wallpaper-pierce-active`；
   - 毫秒级恢复宿主工作区的全部鼠标响应；
   - **焦点抢救（Focus Recovery）**：
     若在穿透期间用户点击了 `<iframe>` 导致宿主失去焦点，松手时主动触发：
     ```javascript
     window.focus();
     if (lastFocusedElement && typeof lastFocusedElement.focus === 'function') {
       try { lastFocusedElement.focus(); } catch (_) {}
     }
     ```
     彻底杜绝松手后键盘无法在编辑器中敲代码的问题。

3. **失焦与切屏安全兜底（Window Blur Guard）**：
   - 监听 `window.addEventListener('blur', exitPierce)`；
   - 监听 `document.addEventListener('visibilitychange', () => { if (document.hidden) exitPierce(); })`；
   - 用户使用 `Alt+Tab` 切屏时，浏览器无法触发 `Alt` 的 `keyup` 事件。通过 `blur` 事件无条件强制退出穿透状态，防止切回窗口时界面被锁死在穿透模式。

## 2. CSS 原子穿透层级规范

```css
/* 默认普通状态：壁纸在最底层，绝不接收任何指针事件 */
#agy-dynamic-scene,
#agy-dynamic-iframe,
#agy-dynamic-video {
  pointer-events: none !important;
  z-index: -999999 !important;
}

/* 激活瞬时穿透模式：html.agy-wallpaper-pierce-active */
html.agy-wallpaper-pierce-active {
  /* 宿主主界面整体穿透，不阻挡鼠标点击直达底层 */
  body > *:not(#agy-dynamic-scene):not(#agy-dynamic-iframe):not(#agy-interact-hud):not(.monaco-modal-dialog) {
    pointer-events: none !important;
    user-select: none !important;
  }

  /* 壁纸容器与子画布/子框架临时接收所有点击与指针事件 */
  #agy-dynamic-scene,
  #agy-dynamic-scene canvas,
  #agy-dynamic-iframe {
    pointer-events: auto !important;
    z-index: 99998 !important; /* 临时提升至界面上层，仅低于 HUD 提示 */
  }

  /* 提示性鼠标光标造型（可反馈当前处于交互态） */
  cursor: crosshair !important;
}
```

## 4. 交付验收标准

- [ ] **按住生效**：长按 `Alt` 键，界面进入穿透态；松开 `Alt` 键，立即退出穿透态；
- [ ] **IDE 打字零干扰**：普通状态下，编辑器选中、光标点击、滚动条拖拽 100% 正常；
- [ ] **Alt 菜单栏防劫持**：在 Windows 下按下 `Alt`，顶部窗口菜单栏不会被错误激活；
- [ ] **Alt+Tab 切屏安全**：按住 `Alt` 并按下 `Tab` 切到外部窗口，再切回 Antigravity，穿透状态已安全重置，界面无死锁；
- [ ] **焦点秒级归位**：在穿透状态下点击壁纸，松开 `Alt` 后，键盘输入立即返回编辑器，无需二次点击 IDE。
