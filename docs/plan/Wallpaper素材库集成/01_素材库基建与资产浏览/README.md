## 二、 核心架构总结
1. **零拷贝架构（Zero-Copy Pipeline）**：直接以只读流对接 Steam 创意工坊目录，零磁盘冗余占用，秒级读取千万级素材；
2. **正交双开关**：动态壁纸与开屏动画可分别绑定不同素材，独立开关、互不争抢；
3. **分级与搜索**：内建基于 Wallpaper 原生元数据的年龄分级筛选（Everyone / Questionable / Mature）与即时模糊搜索。
