# 阶段一计划：核心引擎与零拷贝后端管道

## 1. 阶段目标
本阶段聚焦于底层 **Node.js Sidecar（`sidecars/skin-engine/main.mjs`）** 的架构升级，彻底实现“零拷贝（Zero-Copy）原地直读”与“Wallpaper 格式解析引擎”，确保所有外部壁纸资产无须冗余复制即可秒级被前端访问。

---

## 2. 关键任务与技术实现

### 2.1 配置结构升级 (`config.json` 与 `config.default.json`)
在现有配置中增加对外部库路径与已载入壁纸的记录：
```json
{
  "features": {
    "dynamicWallpaper": {
      "enabled": false,
      "sourceType": "video",       // "video" | "web" | "scene"
      "videoPath": "",             // 相对路径或外部绝对路径
      "wallpaperDir": "",          // 选中的外部壁纸根目录
      "brightness": 0.85,
      "contrast": 1.05
    },
    "bootAnimationConfig": {
      "type": "video",             // "video" | "code"
      "videoPath": ""              // 支持外部壁纸中的视频绝对路径
    },
    "externalWallpaperLibrary": {
      "libraryPath": "",           // 例如 /Users/.../WallpaperMachine/Library
      "autoScan": true
    }
  }
}
```

### 2.2 Wallpaper 项目解析器 (`project.json` 解析引擎)
实现轻量且健壮的目录解析函数 `parseWallpaperFolder(folderPath)`：
1. **清单检查**：检查目标目录下是否存在 `project.json`。
   - 若不存在，尝试检查是否包含常见视频文件，若有则自动生成虚拟元数据；
2. **元数据提取**：
   - `title`: 壁纸标题，支持 fallback 取文件夹名称；
   - `type`: `video` | `web` | `scene` | `application`；
   - `file`: 主文件入口（如 `.mp4`, `index.html`, `scene.json`）；
   - `preview`: 封面文件（如 `preview.jpg`, `preview.gif`, `preview.png`）；
   - `description`: 描述与作者信息；
3. **安全过滤规则**：
   - **严格排除 `type === "application"` 或包含 `.exe` 后缀的项目**；
   - 过滤非法目录穿越，确保只读取安全路径。

### 2.3 双模式扫描引擎
1. **单目录挂载接口**：
   - 验证用户指定的单壁纸目录，解析并返回结构化资产对象；
2. **Library 根目录扫描接口**：
   - 遍历指定根目录下的所有子文件夹；
   - 异步并发解析每个子目录，收集符合规范的壁纸清单；
   - 加入内存缓存（LRU / 目录 mtime 校验），避免重复磁盘 I/O。

### 2.4 零拷贝流媒体与静态资源伺服
改造现有 HTTP 服务，杜绝 `fs.copyFileSync`：
1. **视频流直读 (`/wallpaper.mp4` 与 `/api/video`)**：
   - 接收 `path` 参数（支持已授权外部库的绝对路径）；
   - 支持完整的 HTTP 206 Partial Content 分块断点续传；
2. **封面预览图代理 (`/api/wallpaper-library/preview`)**：
   - 接收 `folderPath` 与 `previewFile`，直接读取并返回图片内容流；
   - 设置 `Cache-Control: public, max-age=86400`，减少前端重复请求；
3. **Web 壁纸静态目录代理 (`/api/wallpaper-library/web-proxy/*`)**：
   - 以指定 Web 壁纸目录为根目录，伺服其中的 HTML、JS、CSS、WebAssembly、图片等资源。

## 3. Sidecar API 接口规范

| 接口地址 | 方法 | 参数 / 请求体 | 响应示例 | 说明 |
| :--- | :---: | :--- | :--- | :--- |
| `/api/wallpaper-library/scan` | `GET` | `?path=<根目录路径>` | `{ ok: true, wallpapers: [...] }` | 扫描根目录下所有壁纸 |
| `/api/wallpaper-library/import-folder` | `POST` | `{ "folderPath": "..." }` | `{ ok: true, wallpaper: {...} }` | 挂载单个壁纸目录 |
| `/api/wallpaper-library/preview` | `GET` | `?folder=<目录>&file=<文件名>` | 图片二进制流 (image/jpeg / gif) | 外部封面图代理 |
| `/api/video` | `GET` | `?path=<绝对路径>` | 视频流 (video/mp4, HTTP 206) | 原地分块视频流伺服 |
