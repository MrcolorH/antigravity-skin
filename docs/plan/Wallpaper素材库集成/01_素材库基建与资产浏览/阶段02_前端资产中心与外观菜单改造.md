# 阶段二计划：前端资产中心与外观菜单改造

## 1. 阶段目标
本阶段聚焦于前端用户交互界面改造（主要位于 `client/modules/appearance-menu.js`），在 Antigravity 宿主原生设置面板的 Appearance 分区中，构建一体化的**外部素材库管理与资产中心**，实现壁纸与开屏动画的所见即所得双向配置。

---

## 2. 关键任务与技术实现

### 2.1 外部素材库设置面板（Wallpaper Library Section）
在外观设置面板中新增专属板块：
1. **素材库路径配置区**：
   - **默认路径智能推荐**：macOS 环境下自动探测并建议 `~/Library/Application Support/WallpaperMachine/Library`；Windows 环境下建议 Steam 默认工坊路径；
   - **载入方式**：
     - 提供「📁 挂载素材库根目录」按钮（基于 `<input type="file" webkitdirectory>` 获取完整绝对路径）；
     - 提供「📄 载入单个壁纸包」按钮（选择包含 `project.json` 的单个壁纸文件夹）；
     - 支持文本框直接粘贴路径并回车载入。
2. **状态指示与快捷刷新**：
   - 实时展示当前已挂载壁纸总数（例如：“已挂载 Wallpaper 库，共 5 款壁纸”）；
   - 提供「🔄 刷新素材库」按钮，方便用户在 WallpaperMachine 中新下载壁纸后即刻同步。

### 2.2 资产中心网格与选择器交互 (Media Asset Hub)
将单一的下拉框重构或增强为**富媒体资产卡片列表**：
1. **资产卡片要素**：
   - **封面缩略图**：流式加载外部封面（`/api/wallpaper-library/preview?folder=...`），支持 GIF 动态预览；
   - **主标题与副信息**：显示壁纸作者和真实中文/英文标题（如《Punishing Lucia花嫁小露》）；
   - **类型徽章（Badge）**：
     - `🎬 视频壁纸` (Video)
     - `🌐 网页壁纸` (Web)
     - `🎨 场景壁纸` (Scene)
     - `🏷️ 内置素材` / `🏷️ Wallpaper 外部库`
2. **双向一键操作动作**：
   - 按钮 A：**「设为动态壁纸」**（即时切换编辑器动态背景，自动同步滤镜、毛玻璃与标题栏透明）；
   - 按钮 B：**「设为开屏动画」**（若为视频或场景封面，直接写入 `bootAnimationConfig`，并在下一次启动或重启时生效）。

### 2.3 现有选择器平滑向下兼容
1. **动态壁纸下拉框增强**：
   - 现有的动态壁纸下拉框中，分类归集并列出：
     - `─── 官方内置素材 ───`
     - `─── WallpaperMachine 外部库 ───`
   - 选中外部壁纸时，自动更新 `dynamicWallpaper.videoPath` 或 `dynamicWallpaper.wallpaperDir`，并保持原地引用。
2. **开屏动画下拉框增强**：
   - 在开机短视频下拉框中，同步纳入外部库中的所有 `type === "video"` 视频（如《库莉姆Cream 病弱人偶》与《Aurora Drift》），用户无须重新上传。

### 2.4 中英双语与国际化（i18n）
在 `client/modules/i18n-engine.js` 中补充对应的本地化词条：
- “Wallpaper 素材库”、“挂载外部壁纸目录”、“设为动态壁纸”、“设为开机动画”、“已过滤不支持的 exe 程序”等。

### 2.5 资产网格分页与资源懒加载设计（Pagination & Resource Lazy Loading）
针对拥有数百上千款壁纸的大型素材库，彻底摒弃 DOM 无限追加的“加载更多”瀑布流，设计轻量级**每页固定 20 款 + 总数带翻页**方案：
1. **分页机制与状态契约**：
   - 每页固定展示 20 款壁纸（`pageSize = 20`）；
   - 翻页控制器置于网格底部，展示「共 ${totalCount} 款 · 第 ${currentPage} / ${totalPages} 页」；
   - 提供「« 首页」、「‹ 上一页」、智能缩略页码胶囊（当前页邻近页码 + 省略号）、「下一页 ›」、「末页 »」以及快速跳转输入框（按 Enter 或失焦即跳转）；
   - 筛选与搜索联动：切换分类（全部/视频/网页/场景）、年龄分级（G/PG-13/R-18）或输入搜索词时，当前页码自动归 1，总页数基于过滤后实时重算；
   - 翻页动作发生时，自动平滑将滚动容器置顶（`scroll.scrollTop = 0`），提供一致的翻阅体验。
2. **三重懒加载与性能守护**：
   - **DOM 节点轻量化（虚拟化卸载）**：DOM 树中恒定只驻留当前页的最多 20 个壁纸卡片节点，上一页的卡片伴随换页自动卸载销毁，彻底根除数百个卡片长期驻留导致的内存激增与渲染卡顿；
   - **图像原生按需懒加载（Lazy Decoded Images）**：卡片内的 `<img>` 标签统一配置 `loading="lazy"` 与 `decoding="async"`，仅在当前页且进入视口时才由浏览器发起图片网络请求与异步解码；
   - **GIF 动图首帧冻结与自动 GC**：当前页渲染时，对包含 GIF 动图的封面自动提取第一帧生成静态 Canvas 覆盖层（鼠标悬停时平滑恢复动效），换页时上一页的 Canvas 与 DOM 一同被浏览器垃圾回收，杜绝多动图同时播放消耗主线程 CPU。

1. 点击「载入单壁纸包」选中 `3812610550` 目录，界面即时解析出封面与标题；
2. 点击「关联 Library 根目录」，界面立即呈现包含视频与场景的所有壁纸卡片；

## 5. 落地补充（交互定稿）

素材库最终以**总开关**形态落地：`externalWallpaperLibrary.enabled` 为唯一开关。

- **开启**：自动隐藏原生「📂 载入新视频壁纸」「📂 载入新开机视频」入口与删除按钮，动态壁纸/开屏动画两个下拉框仅呈现 `─── Wallpaper 外部库 ───` 内容（壁纸 362 项、视频 167 项），资产卡片亦可直接一键应用。
- **关闭**：素材库配置区折叠为一行标题 + 开关，原生载入入口与内置素材分组完整恢复，两者数据完全隔离。
- 关闭时若当前正在使用外部素材，不强制中断播放，以下拉框占位「📁 当前外部素材」+ 提示行告知用户，避免桌面壁纸被突然替换。
