## 二、 核心架构总结
1. **原子性交接（Atomic Presentation）**：彻底摒弃半成品展示，严格在 WebGL2 首帧与多着色器 100% 编译稳定后才放行；
2. **跨平台物理级解耦**：
   - **Windows**：主进程 ASAR 补丁 T=0 秒硬解秒播 + DirectComposition 退出 0ms 秒进；
   - **macOS**：恪守 Gatekeeper 100% 纯净免改包，通过 0ms CDP 视口硬件底板置黑彻底抹除白闪断层。
