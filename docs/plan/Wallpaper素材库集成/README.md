* 🛠️ **[阶段08a：素材库入口由悬浮回归框内集成方案](./阶段08a_素材库入口由悬浮回归框内集成方案.md)**：彻底根除全局悬浮 DOM 计算开销，将素材库入口回归在设置弹窗框内右上角流式内嵌，实现零自激与整洁布局。
* ⚡ **[阶段09：页面闪烁与动图渲染抖动修复](./阶段09_页面闪烁与动图渲染抖动修复.md)**：彻底根除场景壁纸加载黑闪（海报双缓冲 + 550ms Cross-fade 延迟交接）；冻结素材库 GIF 动图首帧覆盖，支持 Hover 平滑试看；消除外观设置菜单每 120ms 全量重建的自激死循环（DOM Mutation 次数从 629次 降至 0）；清理素材库弹窗双重 Header。
* 🎯 **[阶段10：壁纸动态交互与按键穿透引擎](./阶段10_壁纸动态交互与按键穿透引擎.md)**：打通 Web 网页壁纸与 Scene 场景壁纸的点击与指针交互能力；建立「常驻被动视差广播 + 按住修饰键（Alt/Option）瞬时穿透（Hold-to-Interact） + 沉浸漫游模式（Zen Mode）」三阶正交架构；配合防焦点劫持保护与安全沙箱，兼顾日常生产力编码的绝对零误触与高玩壁纸的沉浸乐趣。
