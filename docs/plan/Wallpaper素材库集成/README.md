## 🎯 各子模块核心目标与现状一览

### 1. 🗃️ [子模块一：素材库基建与资产浏览](./01_素材库基建与资产浏览/README.md) `[已完结]`
* **核心职责**：零数据拷贝原地引用、Steam 创意工坊扫描、资产卡片瀑布流、动态壁纸/开机动画双开关、G/PG-13/R-18 年龄分级筛选、独立参数设置弹窗。
* **已落地阶段**：5 个阶段（阶段01 ~ 阶段05）。

### 2. 🎮 [子模块二：多形态渲染与交互引擎](./02_多形态渲染与交互引擎/README.md) `[已完结]`
* **核心职责**：Video 硬件解码适配、HTML5 Web 容器沙箱、WebWallGL WebGL2 实时着色器与木偶骨骼装配、`cover / blur / contain / fill` 展陈几何控制器。
* **已落地阶段**：4 个阶段（阶段01 ~ 阶段04）。

### 3. ⏱️ [子模块三：开机时序与换轨过渡](./03_开机时序与换轨过渡/README.md) `[已完结]`
* **核心职责**：消除动图首帧抖动与海报双缓冲、原子性呈现无黑闪（掐灭场景自带相机淡黑）、macOS 零海报与真·Loading 舱解耦、跨平台（Windows ASAR 补丁 / macOS CDP 硬件锁黑）极速开机保护。
* **已落地阶段**：3 个阶段（阶段01 ~ 阶段03）。

### 4. ⚙️ [子模块四：场景脚本属性与时钟系统](./04_场景脚本属性与时钟系统/README.md) `[已完结]`
* **核心职责**：解决数字时钟/日历日期卡在 `<Clock>` 占位字符问题；开启 SceneScript 脚本引擎并注入本地系统真实时间流；深度对标 WallpaperMachine 构建带有弹簧物理弹性展开的场景属性检查器（Property Inspector）；支持开关/滑条/取色器/下拉框/文本框多态控件映射；实现 `setProperties` 零延迟热更与 Per-Wallpaper 独立存盘。
* **已落地阶段**：4 个阶段（阶段01 ~ 阶段04）。

### 5. ⚡ [子模块五：壁纸交互穿透与按键响应系统](./05_壁纸交互穿透与按键响应系统/README.md) `[已完结]`
* **核心职责**：按住自定义键（默认 `Alt`）瞬时穿透宿主直达壁纸；WebWallGL SceneScript 鼠标点击与射线拾取，完美驱动**点击左右切换人物**等角色壁纸互动；双轨支持 Web 网页壁纸与解压小游戏；Windows 系统菜单防劫持、失焦强制释放与焦点秒级归位；独立弹窗自定义按键与微态 HUD 药丸反馈。
* **已落地阶段**：3 个阶段（阶段01 ~ 阶段03），已通过 12 项自动化集成测试与实机验证。详见 [子模块五实现记录](./05_壁纸交互穿透与按键响应系统/实现记录.md)。
