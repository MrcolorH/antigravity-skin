# 阶段三计划：多形态渲染适配器与体验打磨

## 1. 阶段目标
本阶段聚焦于渲染层的全面升级（主要位于 `client/modules/wallpaper.js` 与 `client/modules/boot-animation.js`），实现对 `video`、`web`、`scene` 多形态壁纸的无缝播放适配，确保从“开机启动动画”到“主界面动态壁纸”的丝滑过渡，并实施严格的内存与电池功耗控制。

---

## 2. 关键任务与技术实现

### 2.1 多形态壁纸渲染适配器 (Multi-Format Wallpaper Player)
在 `client/modules/wallpaper.js` 中将原本单一的 `<video>` 元素解耦为**多态渲染容器（Polymorphic Wallpaper Container）**：

```
┌─────────────────────────────────────────────────────────────┐
│                    动态壁纸宿主容器 (#agy-wallpaper-host)     │
│                                                             │
│   [ 视频形态 ] -> <video id="agy-dynamic-video" autoplay loop> │
│   [ 网页形态 ] -> <iframe id="agy-dynamic-iframe" sandbox>   │
│   [ 场景海报 ] -> <div id="agy-dynamic-scene" class="kenburns">│
│                                                             │
│   [ 滤镜覆盖 ] -> CSS 亮度(--agy-bg-brightness) / 对比度      │
│   [ 毛玻璃层 ] -> 官方工作区透明度穿透与磨砂滤镜             │
└─────────────────────────────────────────────────────────────┘
```

1. **视频形态（Video）适配**：
   - 保持现有极速架构，以 GPU 硬件加速解码外部 MP4/WebM 视频；
   - 监听视频的 `canplay` 事件，在完全就绪后再淡入，杜绝黑屏闪烁。
2. **网页形态（Web）适配**：
   - 动态创建全屏 `<iframe>` 嵌入 `http://127.0.0.1:59288/api/wallpaper-library/web-proxy/<id>/index.html`；
   - 设置合理的 `sandbox="allow-scripts allow-same-origin"`；
   - 默认启用鼠标事件穿透（`pointer-events: none`），确保不阻挡编辑器工作区代码编辑，并可提供开关支持鼠标交互。
3. **场景形态（Scene，如 3812610550 样例）分级呈现**：
   - **基础呈现**：提取原画封面 `preview.jpg` 或动态图 `preview.gif`，配合沉浸式缓动（Ken Burns 微视差呼吸动效），带来极高画质与超低资源消耗；
   - **音频陪伴**：若该 Scene 内部打包了音频（如样例中的 `Swaffer - Gone Angel.mp3`），提供后台轻量氛围音乐播放控制；
   - **系统级桌面透射**：检测若本机运行有 WallpaperMachine，提供一键“纯透工作区”模式，Antigravity 背景彻底透明，直接露出底层 WallpaperMachine 的原生 3D Scene 渲染画面。

### 2.2 开屏动画（Boot Animation）无缝打通与平滑过渡
在 `client/modules/boot-animation.js` 中：
1. **外部视频开机播映**：
   - 无论是内置视频还是外部 Wallpaper 视频，开机瞬间由独立顶层容器接管全屏播放；
   - 同步锁定原生窗口标题栏（WCO）完全透明；
2. **零闪烁交叉淡入淡出（Cross-fade Transition）**：
   - 开机视频播放结束前 400ms，后台预加载主界面动态壁纸；
   - 开机图层以 `opacity: 0` 优雅淡出，主界面壁纸以 `opacity: 1` 丝滑显现，绝无跳帧或瞬间黑底。

### 2.3 性能守卫与功耗优化 (Performance & Battery Guards)
为了确保 Antigravity 作为专业 IDE 的流畅体验，实施严格的性能守卫策略：
1. **窗口失焦/最小化静音与暂停**：
   - 监听 `window.onblur` 与 `document.visibilitychange`；
   - 当 Antigravity 窗口被最小化或完全覆盖时，自动调用 `video.pause()` 挂起解码管线，节省笔记本 CPU/GPU 电池消耗；
   - 窗口重新获得焦点时瞬间平滑 `play()` 唤醒；
2. **内存防泄漏清理**：
   - 切换壁纸时，旧的视频对象显式调用 `pause()`、清空 `src`、释放 Blob 引用，垃圾回收率达到 100%。

## 3. 交付与验证标准
1. **多格式播放验证**：
   - 载入 `3400422354`（视频）：动态壁纸与开机动画均正常 60fps 硬件加速播放；
   - 载入 `3812610550`（场景）：高品质海报沉浸式渲染，毛玻璃滤镜正常叠加；
2. **性能基准验证**：
   - 4K 视频壁纸播放时，Node 进程 CPU 占用小于 0.5%，渲染进程 GPU 解码占用小于 5%；
   - 窗口最小化后视频自动挂起，功耗降至 0；
3. **稳定性验证**：
   - 连续快速切换 20 次不同外部壁纸，内存平稳无泄漏，主窗口 DOM 结构保持干净整洁。
