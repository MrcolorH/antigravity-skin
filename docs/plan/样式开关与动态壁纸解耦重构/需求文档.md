## 1. 需求背景与问题诊断

### 1.1 当前异常现象
1. **开启自定义总开关 + 关闭动态壁纸 = 背景一片黑**  
   用户在「设置 - 外观」开启「自定义皮肤与动效增强」（`features.themeStyles`）但关闭「全局动态视频壁纸」（`features.dynamicWallpaper.enabled`）时，主界面背景呈现纯黑（或深暗底色），未能保持官方原版界面。
2. **界面改造未跟随动态壁纸开关联动卸载**  
   关闭动态壁纸开关后，毛玻璃穿透、侧边栏视觉改造（包含插件修改的侧边栏胶囊/气泡按钮等）、用户提问气泡及折叠胶囊按钮、顶部标题栏透明化与 ContrastGuard 改色等效果依然生效，导致界面无法恢复原版。
3. **「AI 对话样式」选项在无壁纸时依然显示**  
   「AI 对话样式（💬 气泡卡片 / ✨ 模拟原版）」分段按钮行（`#agy-chat-style-row`）目前直接平铺在总开关下。在未开启动态壁纸、主界面保持原版的场景下，该选项依然可见，既无意义又容易引起用户困惑。
4. **无法单独使用「开机引导动画」同时保持主界面原版**  
   用户期望在开启「自定义皮肤与动效增强」总开关后，能够**只开启「开机引导动画」而关闭「动态壁纸」**——即启动时播放定制开屏动画，进入工作区后主界面完全保持官方原版外观。

### 1.2 现有代码根因定位
1. **样式与实例门控过宽**：[client/index.js](../../../client/index.js#L611-L760) 的 `applyFeatures` 与 [client/modules/wallpaper.js](../../../client/modules/wallpaper.js#L232-L257) 仅依据 `features.themeStyles !== false` 就初始化 `wallpaperHandle` 并注入 `#agy-dynamic-wallpaper-style`（[glass-theme.css](../../../client/styles/glass-theme.css)）、挂载 `#agy-wallpaper-backdrop` 与 DOM 观察器。
2. **全局挖空透明 + 纯黑兜底**：[glass-theme.css](../../../client/styles/glass-theme.css#L32-L51) 将 `#agy-wallpaper-backdrop` 固定设为 `#000000 !important`（深色主题 `#0b0f19 !important`），同时 [第 141-167 行](../../../client/styles/glass-theme.css#L141-L167) 将 `html`、`body`、`#root`、`#app`、`main`、`.bg-background`、`.agy-shell`、`.agy-sheet` 等原生底色全部强制置为 `transparent !important`。无壁纸画面垫底时，全透明宿主直接透出纯黑底板。
3. **设置面板层级与文案错位**：[appearance-menu.js](../../../client/modules/appearance-menu.js#L543-L574) 将 `#agy-chat-style-row` 与 `#agy-opt-wallpaper` 并列，且「全局动态视频壁纸」开关副标题仍写着过时的 `“（关闭时仅保留毛玻璃穿透）”`。
4. **后台巡检与原生补丁条件未同步**：
   - [main.mjs](../../../sidecars/skin-engine/main.mjs#L2807-L2819) 的 `checkHealthAndHeal` 与 [client/index.js](../../../client/index.js#L943-L971) 的重入自愈逻辑仅校验 `themeStyles !== false` 来决定是否要求 `#agy-dynamic-wallpaper-style` 存在；
   - [main.mjs](../../../sidecars/skin-engine/main.mjs#L2435-L2484) 与 [loadingOverlay.js](../../../loadingOverlay.js#L39-L50) 在开屏与 WCO 标题栏处理上未形成与「总开关 / 动态壁纸开关」一致的边界隔离。

## 2. 核心设计原则与已确认决策

### 2.1 产品心智模型
1. **「动态壁纸」是「主界面皮肤美化」的唯一触发条件**  
   主界面透明挖空、毛玻璃质感、侧边栏视觉/胶囊按钮改造、对话气泡与折叠按钮、顶部透明标题栏及 ContrastGuard 文字守护，全部为了透出底层动态壁纸而存在，因此**整体跟随「动态壁纸开关」走**。
2. **「动态壁纸关闭 = 主界面 100% 保持官方原版」**  
   当动态壁纸开关关闭（或已开启但尚未选定有效壁纸素材）时，主界面（包含侧边栏样式与气泡按钮、对话流样式、折叠按钮、会话切换行为、标题栏与 WCO）彻底保持官方原版，不注入主界面样式与 DOM 改造。
3. **「开屏动画」独立解耦运行**  
   打开总开关后，用户可单独开启「开机引导动画」而不开「动态壁纸」，启动阶段正常播放开屏，进入主界面后保持官方原版。

### 2.2 已评审确认的边界规则
| 决策项 | 确认结论 |
| :--- | :--- |
| **1. 总开关停用与开屏动画联动** | **总开关「自定义皮肤与动效增强」(`themeStyles`) 停用时，开屏动画 (`bootAnimation`) 一起关闭/不生效**（仅保留上方独立控制的「界面语言」）。 |
| **2. 「AI 对话样式」选项布局位置** | **采用归属子区布局**：将 `#agy-chat-style-row` 移入「全局动态视频壁纸」展开子区域 `#agy-wrap-video-path` 内部（建议作为子区域首项），随动态壁纸开关展开/隐藏。 |
| **3. 会话切换 Loading 过渡 (`createSessionTransitionManager`)** | **随壁纸模式一并停用**：动态壁纸关闭、主界面保持原版时停用居中转圈遮罩，保证零 DOM 侵入、完全沿用官方原版会话切换行为。 |
| **4. 动态壁纸开关开启但尚未选择素材（空素材边界）** | **面板展开配置，主界面暂保持原版**：设置面板内正常展开壁纸配置区与「AI 对话样式」供用户选择；在选中有效素材前，渲染层不提前挂载 `#agy-wallpaper-backdrop` 黑底或注入 `glass-theme.css`，避免等待选材期间黑屏。 |

## 4. 详细功能需求（Functional Requirements）

### FR-1：定义统一的「壁纸皮肤激活态」与「开屏动画激活态」
在前端、Sidecar 与 Windows 原生补丁中，统一收敛为两套清晰的派生判定规则：
- **开屏动画有效条件（`isBootActiveEffective`）**：  
  `cfg.enabled !== false && cfg.features?.themeStyles !== false && cfg.features?.bootAnimation === true`
- **壁纸皮肤激活态（`isWallpaperSkinActive`）**：  
  `cfg.enabled !== false && cfg.features?.themeStyles !== false && cfg.features?.dynamicWallpaper?.enabled === true && hasValidWallpaperSource(cfg.features.dynamicWallpaper)`  
  - 其中 `hasValidWallpaperSource` 判定：`sourceType === 'video'` 时 `videoPath` 非空；`sourceType === 'web' | 'scene'` 时 `wallpaperDir` 非空（兼容缺省 `sourceType` 推导）。

### FR-2：主界面视觉改造严格绑定 `isWallpaperSkinActive`
当且仅当 `isWallpaperSkinActive === true` 时，才启用并维持以下全部主界面改造；**只要 `isWallpaperSkinActive === false`，不得初始化或保留以下任何能力**：
1. **底层渲染与纯黑防透底板**：
   - `#agy-dynamic-video` / `#agy-dynamic-video-backdrop` / `#agy-dynamic-iframe` / `#agy-dynamic-scene` / `#agy-dynamic-audio`；
   - `#agy-wallpaper-backdrop`（严禁在非激活态下创建或保留，杜绝黑色底板裸露）。
2. **全量主界面 CSS 样式注入**：
   - `#agy-dynamic-wallpaper-style`（[glass-theme.css](../../../client/styles/glass-theme.css)）、`#agy-scene-style`、`#agy-wallpaper-pierce-style`；
   - `<html>` 上的 `agy-chat-native` 类（原版界面无需“模拟原版”）。
   - 涵盖的界面范围包括：根容器透明化、**侧边栏毛玻璃及所有侧边栏胶囊/气泡按钮**（分类大标题胶囊、文件夹项目卡片、会话选中/悬停胶囊、会话悬停操作栏胶囊、新建对话高亮胶囊、导航图标/文字染色）、用户提问气泡卡片、AI 回复毛玻璃卡片、工具折叠/状态胶囊、底部输入栏毛玻璃、语音胶囊、排队消息卡片、弹窗与独立视图毛玻璃美化等。
3. **DOM 增强与交互观测器**：
   - `enhanceUserBubbles` / `bubbleObserver` 注入的用户消息折叠按钮（`.user-bubble-toggle-btn` / `.agy-user-collapse-btn`）及相关 `data-user-*` / `data-agy-enhanced` / `.user-bubble-card` 标记；
   - `createSessionTransitionManager` 会话切换居中转圈遮罩（`#agy-session-loader-overlay`）与路由/点击监听；
   - 壁纸按键穿透交互（Hold-to-Interact 修饰键监听、`#agy-interact-hud`）与主界面 `unifiedObserver`。
4. **顶部标题栏（WCO）与明暗对比度守护**：
   - `detectWallpaperLuminance` 采样与 `runContrastGuard` 文字对比度强制翻色；
   - `<html>` 上的 `agy-dark-wallpaper` / `agy-light-wallpaper` / `agy-dark-topbar` / `agy-light-topbar` / `agy-native-dark` / `agy-native-light` 类与 `data-agy-top-lum` / `data-agy-wallpaper-lum` / `data-agy-lum-profile` / `data-agy-has-measure` / `data-agy-has-video` 及元素 `data-agy-cg` 属性；
   - `syncTitleBarOverlay` 透明底色与符号色接管（非激活态且非开屏播放中，保持/还原官方原生实色标题栏）。

### FR-3：热切换与实时无损回滚（无需重启）
当用户关闭「全局动态视频壁纸」、关闭「自定义皮肤与动效增强」总开关，或清空/删除壁纸素材导致 `isWallpaperSkinActive` 由 `true` 变为 `false` 时，必须立即执行完整清理：
1. 调用 `wallpaperHandle.destroy()` 并置空句柄，卸载视频/WebGL/iframe/音频及 `#agy-wallpaper-backdrop`；
2. 移除 `#agy-dynamic-wallpaper-style`、`#agy-scene-style`、`#agy-wallpaper-pierce-style`、`#agy-interact-hud`、`#agy-session-loader-overlay` 等全部注入节点；
3. 清除全部 `.user-bubble-toggle-btn`、`.agy-user-collapse-btn`、`[data-agy-collapse-btn]` 与 `data-user-collapsed` / `data-user-collapsible` / `data-agy-enhanced` / `data-agy-collapsed` / `.user-bubble-card` 等气泡改造痕迹，恢复节点 `maxHeight` / `overflow`；
4. 执行 `resetContrastGuard()`，并移除 `<html>` 上的全部 `agy-*` 主题/明暗/模拟原版类名与 `data-agy-*` 数据属性；
5. 调用 `syncTitleBarOverlay(true)` 将标题栏与 WCO 恢复为宿主当前浅色/深色原生配色。

### FR-4：开机引导动画独立解耦与无黑屏退出
1. **总开关协同停用**：
   - 在 [client/index.js](../../../client/index.js#L871-L898)（`shouldAbandonBootAnimation`）、[client/modules/boot-animation.js](../../../client/modules/boot-animation.js#L156-L171)、[sidecars/skin-engine/main.mjs](../../../sidecars/skin-engine/main.mjs#L2435-L2484) 及 [loadingOverlay.js](../../../loadingOverlay.js#L312) 中，统一要求 `themeStyles !== false` 才激活开机动画。当总开关关闭时，冷启动不触发开机动画、不注入黑底防白闪样式。
   - 关闭总开关时保留用户此前选择的开机动画素材路径与开关状态（或仅在运行时失效），以便重新开启总开关后无需重新配置素材。
2. **仅开开屏 + 保持原版主界面（`themeStyles: true`, `dynamicWallpaper.enabled: false`, `bootAnimation: true`）**：
   - 启动阶段正常执行视频/代码开屏动画与就绪等待（`__agyIsHostTrulyReady` 及 `loadingOverlay.js` 不等待壁纸元素与 `#agy-dynamic-wallpaper-style`）；
   - 开屏播放期间临时维持黑色防白闪幕布与透明标题栏锁；
   - 开屏退场淡出时（`closeVideoBoot` / `closeCustomBoot` / `doRemove` / `cleanMacAntiFlashAndNotify` / `restoreTitleBarOverlay`），彻底清除 `#agy-macos-anti-flash` 与 `html/body` 黑色内联背景，停止 WCO 透明锁定并恢复原生标题栏实色，淡出后直接露出 **100% 官方原版主界面**。
3. **设置内「▶️ 立即预览」兼容**：
   - 在无壁纸的纯原版状态下点击开机动画预览并退出后，主界面同样完整保持原版，不残留黑屏或透明标题栏。

### FR-5：外观设置面板 UI 与交互重构（[appearance-menu.js](../../../client/modules/appearance-menu.js)）
1. **「AI 对话样式」移入动态壁纸子配置区**：
   - 将 `#agy-chat-style-row`（「AI 对话样式 Chat Style：💬 气泡卡片 / ✨ 模拟原版」）移入 `#agy-wrap-video-path` 容器内顶部（紧邻「使用 Wallpaper 素材库」之前，以底部分割线区分）；
   - 当「全局动态视频壁纸」开关关闭时，随 `#agy-wrap-video-path` 一并隐藏（`display: none`）；打开开关时一并展开，实时保留和同步 `chatStyleMode`（`bubble` / `native`）。
   - 注意同步更新幂等重渲染检测条件（[appearance-menu.js](../../../client/modules/appearance-menu.js#L532) 及事件绑定作用域），确保 DOM 结构变更后幂等巡检不会误销毁重建面板。
2. **说明文案纠偏**：
   - **「全局动态视频壁纸」副标题**：由 `在底层循环播放流媒体壁纸（关闭时仅保留毛玻璃穿透）` 修改为 `开启后呈现动态壁纸并启用全局毛玻璃与气泡美化；关闭后主界面恢复官方原版`；

3. **无壁纸样式依赖的设置面板可读性**：
   - 当动态壁纸关闭、`glass-theme.css` 未注入时，外观设置卡片内插件自建组件（`界面语言`、`自定义皮肤与动效增强` 开关、开机引导动画子区、热更新区域）须在原生浅色/深色主题下保持正常可读性与对齐。

### FR-6：Sidecar 与原生补丁状态机一致性对齐
1. **Sidecar 健康巡检（[main.mjs](../../../sidecars/skin-engine/main.mjs#L2789-L2840)）**：
   - `checkHealthAndHeal` 中的 `needStyle` 必须改为 `isWallpaperSkinActive` 语义（同时校验 `themeStyles !== false && wallCfg?.enabled === true && wallHasSource`）。当动态壁纸关闭或未选素材时，不再因缺少 `#agy-dynamic-wallpaper-style` 而误判失活或反复触发重注入。
   - 冷启动预设透明标题栏（[main.mjs](../../../sidecars/skin-engine/main.mjs#L2452-L2460)、[第 2731-2737 行](../../../sidecars/skin-engine/main.mjs#L2731-L2737)）仅在「开机动画有效激活」或「壁纸皮肤激活态」下生效；否则保持宿主原生标题栏。
2. **Windows 原生补丁（[loadingOverlay.js](../../../loadingOverlay.js)）**：
   - 全局及实例级 `setTitleBarOverlay` 拦截钩子仅在「壁纸皮肤激活态」或「开屏动画播放期间」将底色锁定为 `rgba(0, 0, 0, 0)`；当开屏动画结束且动态壁纸未激活时，放行原生实色标题栏设定，并同步恢复主窗口原生背景色（避免长期锁死 `#000000`）。
3. **客户端重入自愈（[client/index.js](../../../client/index.js#L943-L971)）**：
   - `__AG_SKIN_ATTACHED__` 重入时的 `needStyle` 必须与 `needWallpaper` 一致（均基于 `isWallpaperSkinActive`）；若检测到无需皮肤但 DOM 中仍残留 `#agy-dynamic-wallpaper-style` / `#agy-wallpaper-backdrop` / 壁纸媒体元素，自动触发完整清理。

## 6. 验收标准（Acceptance Criteria）

- [ ] **AC-1（核心黑屏消除）**：开启「自定义皮肤与动效增强」且关闭「全局动态视频壁纸」，客户端在原生浅色与深色模式下均**不出现黑屏或纯黑底板**。
- [ ] **AC-2（主界面全面原版）**：在 AC-1 状态下，侧边栏（背景、分类标题胶囊、项目卡片、会话行、悬停操作栏、新建对话胶囊）、聊天区（用户提问与 AI 回复样式、无折叠胶囊按钮）、底部输入栏、会话切换效果、顶部标题栏与 Windows 窗口控制按钮（WCO）均**100% 保持官方原版**。
- [ ] **AC-3（单独开屏动画）**：开启「自定义皮肤与动效增强」+ 关闭「全局动态视频壁纸」+ 开启「开机引导动画」时，冷启动与「▶️ 立即预览」均正常播放开屏动画，退场后主界面**100% 保持官方原版**，无闪黑、无透明顶栏残留。
- [ ] **AC-4（总开关联动开屏关闭）**：关闭「自定义皮肤与动效增强」后，即使历史配置中保留了开屏素材，冷启动也不再播放开屏动画，且主界面保持 100% 官方原版（界面语言功能仍独立正常工作）。
- [ ] **AC-5（AI 对话样式选项联动）**：「AI 对话样式（气泡卡片 / 模拟原版）」位于动态壁纸子配置区内；关闭动态壁纸开关时该选项不可见，打开动态壁纸开关时可见并可正常切换生效。
- [ ] **AC-6（空素材边界无黑屏）**：未选择有效壁纸素材时打开动态壁纸开关，面板正常展开供选择素材与配置对话样式，主界面在选定有效素材前仍保持原版不黑屏；选中素材后立即正常启用壁纸与毛玻璃。
- [ ] **AC-7（热切换无损回滚与长驻稳定）**：运行中反复切换「动态壁纸」或「总开关」开/关，无需重启即可干净回滚到原版或恢复皮肤；仅开屏无壁纸长驻运行期间，Sidecar `checkHealthAndHeal` 不误判重注入。
